# 신선대·감만 접안 게임 (busan-berth-dock)

부산항터미널(BPT) 신선대·감만 터미널의 **실제 선석배정 현황**을 5분마다 읽어 와서,
다음 입항 예정 선박을 배정된 선석에 직접 조종해 접안시키는 아케이드 게임입니다.

- 지금 접안 중인 실제 선박들이 선석에 놓여 있고(장애물), 플레이어는 다음 입항선을 조종합니다.
- 배정표의 접안현(S=우현, P=좌현)대로 붙여야 성공합니다.
- 안벽·타선과 2 kn 이상으로 부딪히면 사고로 실패합니다.

## 데이터 출처

- BPT 정보조회서비스 「선석배정 현황(T)」 (`info.bptc.co.kr`) 를 서버(`/api/berths`)에서 읽어 EUC-KR을 디코딩하고 표를 파싱합니다.
- 4분 메모리 캐시 + CDN `s-maxage=300` 으로 원 사이트 부하를 줄입니다.
- 사이트 접속이 안 되면 샘플 배정표로 돌아가며, 화면 상단 칩에 "샘플 데이터"로 표시됩니다.
- 선박 길이는 제원 데이터가 없어 양하·선적 물량으로 추정합니다. 선석 배치도는 게임용으로 단순화했습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ↑ / W | 엔진 올림 (전진) |
| ↓ / S | 엔진 내림 (후진) |
| Space | 엔진 정지 |
| ← / A, → / D | 좌타 / 우타 |
| Q / E | 바우스러스터 (선수를 좌/우로 밀기) |
| R | 다시 시작 |
| Enter | 입항 시작 |

모바일에서는 화면 하단 터치 버튼으로 같은 조작을 합니다.

## 개발

```bash
npm install
npm run dev   # http://localhost:3002
npm run build
```
